## 1. 总体架构

游戏采用**"ScriptableObject 数据 + MonoBehaviour 运行时"**的经典 Unity 分层：

```
┌─────────────────────────── ScriptableObject 层（静态数据，本文件重点） ───────────────────────────┐
│                                                                                                  │
│  GameConfig ──┬─→ ItemizationConfig        （装备词条池 / 宝石孔位规则）                            │
│               ├─→ LootConfig               （掉落向量 / 稀有度概率）                               │
│               ├─→ HealingPotionUpgradeData （药水升级档位）                                        │
│               ├─→ DifficultyTierConfig[]   （难度层级倍率）                                        │
│               └─→ 各类成长曲线（敌人血量/伤害成长、经验曲线、Paragon 曲线）                          │
│                                                                                                  │
│  ItemData ─┬─→ GemData / RuneData / RandomEquipment     （物品 / 宝石 / 符文 / 随机装备）           │
│            ├─→ EquipmentEffectBehavior[]  （11+ 种装备特效，多态）                                  │
│            ├─→ AbilityLevelGrant[]        （装备授予技能等级）                                      │
│            └─→ StatModifier[] FixedStats  （固定属性）                                             │
│                                                                                                  │
│  AbilityData ─→ List<AbilityEffect> Effects [SerializeReference] （技能效果链，16 种多态）          │
│  StatusEffectData ─→ List<StatusEffectBehavior> Behaviors [SerializeReference] （14 种多态）        │
│  TalentData ─→ LeveledStatModifier[] + TalentEffectBehavior[] （36+ 种多态天赋效果）                │
│  RuneSetData / LifeSkillNodeData / MapData / Enemy / SlaveData / HeroData / RecipeData ...        │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
                                        ↓ 运行时读取
┌──────────────────────────── 运行时层（MonoBehaviour） ────────────────────────────────────────────┐
│  Character（属性计算 / 伤害结算）           StatusEffectController（Buff 池 / 属性聚合）             │
│  Enemy : Character                        PlayerAbilityController（技能施放）                      │
│  StatusEffectData → StatusEffectController → List<StatModifier> → Dictionary<StatType,double>     │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**关键设计结论**：SO 层只负责**声明数据**，所有计算逻辑都在运行时 `Character` / `StatusEffectController` 中，且属性统一走**三层修饰符聚合**（详见 §6.1）。

## 2. ScriptableObject 清单与功能说明

### 2.1 根配置类

| SO 名称 | 基类 | 功能说明 | 实例 |
|---|---|---|---|
| `GameConfig` | `ScriptableObject` | **全局数值中枢**：等级上限、敌人成长曲线、经验公式、Paragon 曲线、强化规则、精英倍率、难度档位、挂机规则 | 2 |
| `ItemizationConfig` | `ScriptableObject` | **装备词条规则**：每个部位的词条池（Primary/Secondary）、宝石孔位数、孔位解锁等级 | 1 |
| `LootConfig` | `ScriptableObject` | **掉落规则**：掉落向量（NoDrop/Common/Uncommon/Rare/Legendary）、金币倍率、神圣/宝石概率、掷骰次数 | 2 |
| `HealingPotionUpgradeData` | `ScriptableObject` | 药水升级档位（等级需求 / 金币 / 材料） | 1 |
| `GraphicsConfig` | `ScriptableObject` | 字体配置（无战斗数值） | 1 |
| `AudioConfig` | `ScriptableObject` | 音频表（无战斗数值） | 1 |
| `LeaderboardCodex` | `ScriptableObject` | 排行榜快照编解码 | 1 |
| `BloodPreset` | `ScriptableObject` | 血液特效预设 | — |

### 2.2 物品与装备域

| SO 名称 | 基类 | 功能说明 |
|---|---|---|
| `ItemData` | `ScriptableObject` | **物品主表**：类型/稀有度/售价/掉落等级区间/装备槽/固定属性/装备特效/技能授予/宝箱掉落表 |
| `GemData` | `ItemData` | 宝石：**按镶嵌位置类别**提供三组不同加成 —— `ArmorBonuses` / `AccessoryBonuses` / `WeaponBonuses`（各为 `GemBonus[]`，即 `{Stat, Modifier, Value:float}`） |
| `RuneData` | `ItemData` | 符文：`Attributes : RuneAttribute[]`（`{Stat, Modifier, Value:LeveledFloat}`，随符文等级成长）+ `Effects : EquipmentEffectBehavior[]` + `Set : RuneSetData` + `AllowDuplicateEquip : bool` |
| `RandomEquipment` | `ItemData` | 随机装备模板（指定槽位，属性由 `ItemizationConfig` 词条池生成） |
| `RuneSetData` | `ScriptableObject` | 符文套装：`Bonuses : RuneSetBonus[]`，每个档位含 `RequiredCount` + `Modifiers` + `Effects` + `AbilityLevels`（**实际数据为 2/4/6 件三档**） |
| `RecipeData` | `ScriptableObject` | 合成配方：材料、产出、金币消耗 |
| `RecipeBook` | `ScriptableObject` | 配方集合 |
| `ItemizationConfig` | `ScriptableObject` | 词条池与孔位规则（见上） |

### 2.3 装备特效域（`EquipmentEffectBehavior`，多态，运行时通过 `bzb()` 产出 `IEnumerable<StatModifier>`）

| SO 名称 | 功能说明 |
|---|---|
| `EquipmentEffect_StatModifier` | 基础属性附加（可带 `RequiredStatus` / `SelfCondition` 条件） |
| `EquipmentEffect_AllStats` | 全主属性附加（Strength/Dexterity/Intelligence） |
| `EquipmentEffect_StatConversion` | 属性转化：`SourceStat × Fraction → TargetStat` |
| `EquipmentEffect_StatPerStatusStack` | 每层状态提供属性：`ValuePerStack × 层数` |
| `EquipmentEffect_ConditionalCritChance` | 条件暴击率（按目标状态 `TargetStateCondition`） |
| `EquipmentEffect_ConditionalCritDamage` | 条件暴击伤害 |
| `EquipmentEffect_AbilityTagCritDamage` | 指定技能标签暴击伤害 |
| `EquipmentEffect_AbilityModifier` | 技能参数修改（标签/技能 + `ModifiedStat`） |
| `EquipmentEffect_AbilityEffectOverride` | 第 N 次施放替换技能效果链 |
| `EquipmentEffect_AbilityOnCastCount` | 累计施放 N 次触发效果 |
| `EquipmentEffect_AbilityTriggerAbility` | 概率触发另一技能 |
| `EquipmentEffect_AbilitySummonAbility` | 召唤技能附加技能 |
| `EquipmentEffect_AbilityProjectileCount/Size/Lifetime/Deflect` | 投射物数量/大小/存活/弹射 |
| `EquipmentEffect_AbilitySpawnCount` / `AbilityStrikeSplash` | 生成数量 / 打击溅射 |
| `EquipmentEffect_AbilityChannelModifier` | 引导速度与时长 |
| `EquipmentEffect_ChannelAllowedCastTag` | 引导期间允许的施法标签 |
| `EquipmentEffect_StatusOnHit/Kill/CritTaken/LowHealth/ResourceConsumed` | 命中/击杀/受暴击/低血/消耗资源时施加状态 |
| `EquipmentEffect_StatusApplyStatus` | 状态链式转化 |
| `EquipmentEffect_GainStatusEverySecond` | 定时获得状态 |
| `EquipmentEffect_SelfStatusStackTriggerAbility` | 自身状态叠满触发技能 |
| `EquipmentEffect_TriggerEffectsOnHit/Crit/PotionUse` | 命中/暴击/喝药触发效果链 |
| `EquipmentEffect_TriggerKillEffectsOnHit` | 命中时执行击杀特效 |
| `EquipmentEffect_TriggerAbilityTwice` | 概率双次施放 |
| `EquipmentEffect_TriggerAbilityCooldownReduction` | 触发技能冷却缩减 |
| `EquipmentEffect_TriggerDotDetonation` | DOT 引爆 |
| `EquipmentEffect_BeingHitTriggerAbility` | 受击触发技能 |
| `EquipmentEffect_FreeCast` | 概率免费施放 |
| `EquipmentEffect_DamagePerManaFraction` | 按法力比例提供增伤 |
| `EquipmentEffect_TrapRearm` | 陷阱重新布置 |
| `TriggerEffectOnStatus` | 状态到期/持续期间触发效果链 |

### 2.4 技能域

| SO 名称 | 基类 | 功能说明 |
|---|---|---|
| `AbilityData` | `ScriptableObject` | **技能表**：目标形状、范围、冷却、耗蓝、引导参数、效果链（`SerializeReference`）、动画与音效 |
| `DamageEffect` | `AbilityEffect` | **伤害效果**（核心） |
| `StatScaledDamageEffect` | `AbilityEffect` | 按属性区间缩放的伤害 |
| `HealEffect` | `AbilityEffect` | 治疗 |
| `GainManaEffect` | `AbilityEffect` | 回蓝 |
| `ApplyStatusEffectEffect` | `AbilityEffect` | 施加状态 |
| `DashEffect` | `AbilityEffect` | 位移 |
| `KnockbackEffect` / `PullEffect` | `AbilityEffect` | 击退 / 拉拽 |
| `StaggeredStrikesEffect` | `AbilityEffect` | 多段延迟打击 |
| `EveryNthCastEffect` | `AbilityEffect` | 每 N 次施放强化 |
| `SpawnProjectileEffect` / `SpawnBeamEffect` / `SpawnParticleAoEEffect` / `SpawnGroundZoneEffect` | `AbilityEffect` | 投射物 / 光束 / 粒子 AOE / 地面区域 |
| `SpawnTransientCharacterEffect` | `AbilityEffect` | 生成临时角色 |
| `ReviveAllEffect` | `AbilityEffect` | 全体复活 |

### 2.5 状态（Buff/Debuff）域

| SO 名称 | 基类 | 功能说明 |
|---|---|---|
| `StatusEffectData` | `ScriptableObject` | **状态表**：层数、持续时间、Tick 频率、行为链（`SerializeReference`） |
| `StatModifierBehavior` | `StatusEffectBehavior` | 属性修饰（`LeveledStatModifier[]`） |
| `DamageReductionBehavior` | `StatusEffectBehavior` | 减伤（可过滤伤害类型） |
| `DamageDealtReductionBehavior` | `StatusEffectBehavior` | 造成伤害降低 |
| `DamageAmplificationBehavior` | `StatusEffectBehavior` | 易伤放大 |
| `DamageOverTimeBehavior` | `StatusEffectBehavior` | 持续伤害（含重应用模式） |
| `HealOverTimeBehavior` | `StatusEffectBehavior` | 持续治疗 |
| `ShieldBehavior` | `StatusEffectBehavior` | 护盾（按最大生命百分比） |
| `VulnerableBehavior` | `StatusEffectBehavior` | **易伤标记**（触发 ×1.3 固定乘区） |
| `StunnedBehavior` / `ImmobilizedBehavior` | `StatusEffectBehavior` | 眩晕 / 定身 |
| `CCDiminishBehavior` | `StatusEffectBehavior` | 控制递减 |
| `ImmuneBehavior` | `StatusEffectBehavior` | 免疫 |
| `SourceCritChanceBonusBehavior` | `StatusEffectBehavior` | 来源暴击率加成 |
| `PeriodicAreaEffectBehavior` / `OnEndEffectBehavior` | `StatusEffectBehavior` | 周期 AOE / 结束触发 |

### 2.7 世界 / 关卡 / 其他

| SO 名称 | 功能说明 |
|---|---|
| `MapData` | 地图：敌人等级区间、遭遇池、精英概率、神话难度参数（`MythicBaseHP` 等）、采集生成 |
| `TownData` / `FishingMapData` | 城镇 / 钓鱼场景 |
| `Enemy` (`: Character`) | 敌人配置：技能、阶段、掉落、神话体型 |
| `SlaveData` | 从属（宠物）：物种、稀有度、容量、被动、技能 |
| `HeroData` | 英雄：主属性、职业、初始武器、技能列表 |
| `LifeSkillNodeData` / `LifeSkillNodeEffect` | 生活技能树（9 种效果类型） |
| `QuestData` | 任务：需求、对话 |
| `LuckyWheelData` | 幸运转盘：花费、段位权重 |
| `HealthPotionConfig` | 药水：即时治疗量、HOT 比例与时长、冷却 |
| `WheelRewardType` | 转盘奖励类型 |
