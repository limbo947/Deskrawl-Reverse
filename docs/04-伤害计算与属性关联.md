## 6. 计算公式与逻辑

### 6.1 属性聚合（三层模型）✅ **核心**

来源：`StatusEffectController.bgh`（RVA `0x4D5E10`）+ `bgg`（RVA `0x4D5B70`）

每个 `StatType` 在 `StatusEffectController` 中维护三个字典：

| 字典偏移 | 对应 | 聚合方式 |
|---|---|---|
| `+0x38` | `Flat` | **求和** |
| `+0x40` | `PercentAdd` | **求和** |
| `+0x48` | `PercentMult` | **连乘** `Π(1+v)` |

**最终公式**：

```
                 ┌ 求和 ┐                ┌ 求和 ┐          ┌── 连乘 ──┐
Final(stat) = ( Base + Σ Flat ) × ( 1 + Σ PercentAdd ) × ( Π (1 + PercentMult) )
```

`StatModifier` 入池逻辑（`bgg` 的 `switch (Type)`）：
- `Type == 0 (Flat)` → `dictFlat[stat] += value`
- `Type == 1 (PercentAdd)` → `dictAdd[stat] += value`
- `Type == 2 (PercentMult)` → `dictMult[stat] *= (1 + value)`

**读取路径**：

```
Character.bje(stat)   ← 仅返回角色基础字段（BaseDamage/BaseCritChance/...）
        ↓
Character.bjd(stat)   = StatusEffectController.bgh(stat, bje(stat))    ← 装备/天赋/Buff 在此叠加
        ↓
Character.bjc(stat)   = clamp(bjd(stat))                               ← 对 4 个属性封顶 0.85
```

**封顶规则**（`0x4A9C30`，位掩码 `0x402010` → bit 4/13/22，加特判 37）：

| 属性 | 上限 |
|---|---|
| `CritChance(4)` | 0.85 |
| `CooldownReduction(13)` | 0.85 |
| `Dodge(22)` | 0.85 |
| `ManaCostReduction(37)` | 0.85 |

> **数值设计含义**：这是全游戏最重要的结构。堆同源百分比会**边际递减**，堆不同源则**相互乘算**。

### 6.2 伤害计算总链路 ✅

```
【攻击方】DamageEffect.te  (RVA 0x497FE0)
┌──────────────────────────────────────────────────────────────────────────────┐
│ 1. attackDamage = f(DamageEffect.BaseDamage, AttackScaling.wo(level), 攻强)   │
│ 2. typeMul      = Character.bkn(damageType)                                   │
│                 = 1 + Final(Damage<type>) + Final(DamagePercent)              │
│                   ↑ 同池加算（物理 312.4% + 全伤害 88.3% → ×5.007）            │
│ 3. dmg          = attackDamage × typeMul                                      │
│ 4. 暴击判定：                                                                  │
│       critChance = min(0.85, Final(CritChance) + Buff加成 + 技能接口bkl)       │
│       if (Random() < critChance):                                             │
│            dmg ×= 1 + CritDamageBonus(CritDamage + BaseCritDamage + 装备)      │
│ 5. dmg ×= Random(0.9, 1.1)          ← 每次命中 ±10% 浮动                        │
│ 6. dmg ×= Character.bko(target)                                                │
│       = 1 + Σ ConditionalDamage（10 项，按目标状态条件触发）                    │
└──────────────────────────────────────────────────────────────────────────────┘
                                    ↓ 逐目标
【受击方】Character.bkq → bku  (RVA 0x681AC0 / 0x6821F0)
┌──────────────────────────────────────────────────────────────────────────────┐
│ 7.  dmg = 攻击方SEC.bgl(dmg, type)        ← 攻击方状态效果增/减伤              │
│ 8.  if (目标.SEC.Vulnerable):  dmg = round(dmg × 1.3)   ← 固定易伤乘区          │
│ 9.  dmg = 受击方SEC.bgk(dmg, type)                                            │
│ 10. dmg ×= (1 − armorResist)                                                  │
│        armorResist = resist / (resist + 50 × max(1, level))                    │
│        resist = Physical ? Final(Armor) : Final(MagicResist)                   │
│ 11. dmg ×= (1 − clamp(Final(Damage<type>Reduction)))   ← 51/52/53/54/49/55      │
│ 12. dmg ×= (1 − clamp(Final(DamageReduction)))         ← 64                    │
│ 13. dmg = max(1, dmg)                     ← 最低 1 点                          │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 6.2.1 `bkn` —— 元素/物理伤害乘区（RVA `0x681280`）✅

```
DamageType → StatType 映射（跳转表 RVA 0x681368）：
  Physical  → DamagePhysical (23)
  Fire      → DamageFire     (24)
  Cold      → DamageCold     (25)
  Lightning → DamageLightning(26)
  Poison    → DamagePoison   (27)
  Arcane    → DamageArcane   (28)

typeMul = 1.0 + Final(映射属性) + Final(DamagePercent=65)
```

> 汇编证据：`movsd xmm6, [1.0]` → `addsd xmm6, Final(元素)` → `addsd xmm6, Final(65)`。

> **重要**：`DamagePhysical` 等**元素属性**与 `DamagePercent`（全伤害加成）**属于同一加算池**。这解释了为什么面板上"物理 312.4% + 全伤害 88.3%"实际是 `×5.007`，而不是 `×4.124 × 1.883`。

#### 6.2.2 `bko` —— 条件伤害加算池（RVA `0x681380`）✅

返回 `1 + Σ`，各项判定条件：

| 条件（读目标状态） | 判定依据 | 加入属性 |
|---|---|---|
| 目标 HP 比例 **> 0.8** | `comisd 0.8` | `DamageVsHealthy(29)` |
| 目标 HP 比例 **< 0.3** | `comisd 0.3` | `DamageVsInjured(30)` |
| 目标被减速 | `Character.bkb()` | `DamageVsSlowed(31)` |
| 目标被定身 | `bkd() \|\| bke()` | `DamageVsImmobilized(43)` |
| 目标流血 | `bkj(self,target)` | `DamageVsBleeding(45)` |
| 目标中毒 | — | `DamageVsPoisoned(46)` |
| 目标灼烧 | — | `DamageVsBurned(63)` |
| 远程命中 | — | `DamageVsDistant(58)` |
| 目标为精英 | — | `DamageVsElite(32)` |
| 目标处于易伤状态 | `SEC[+0x60]` 标志 | `VulnerableDamage(40)` |

> 汇编特征：入口 `movsd xmm6, 1.0`，其后**全部为 `addsd`**，无任何 `mulsd` → 铁证为**同池加算**。

#### 6.2.3 暴击（RVA `0x680140` / `0x681090` / `0x494520`）✅

```
# 暴击率（bjl，0x680140）
critFromStats = clamp(Final(CritChance), 0, 0.85)

# 完整暴击率（bkk，0x681090）
critChance = clamp( bjl() + SEC.bgm(target) + bkl(target, ability) , 0, 0.85 )
                                    ↑ Buff 加成      ↑ 装备/天赋条件暴击

# 暴击伤害加成（0x494520）
critDamageBonus = 0x4942D0()              # = Final(CritDamage)
                + 装备/天赋加成
                  ↓ 经 Character.bkm(float)
critMultiplier  = 1 + critDamageBonus

# 最终（DamageEffect.te）
dmg = crit ? dmg × (1 + critDamageBonus) : dmg
```

> 面板 381.2% 暴伤 → 暴击时 `×4.812`，独立乘区。

#### 6.2.4 减伤（RVA `0x682150` / `0x6821F0`）✅

```
# 护甲/魔抗曲线（bkt）
resist    = (damageType == Physical) ? Final(Armor) : Final(MagicResist)
L         = max(1, attackerLevel)
armorResist = resist / (resist + 50.0 × L)          # 常量 50.0 @ 0x18362A350

# 元素与全局减伤（bku 跳转表 RVA 0x682384）
Physical  → PhysicalDamageReduction (51)
Fire      → FireDamageReduction     (52)
Cold      → ColdDamageReduction     (53)
Lightning → LightningDamageReduction(54)
Poison    → PoisonDamageReduction   (49)
Arcane    → ArcaneDamageReduction   (55)

final = dmg × (1 − armorResist) × (1 − clamp(elemRed,0,1)) × (1 − clamp(DamageReduction,0,1))
```

**减伤侧特性**：三项减伤为**乘法叠加**，因此互不稀释，堆任何一项都线性有效；护甲为**递推曲线**，收益递减。

#### 6.2.5 易伤（Vulnerable）✅

| 机制 | 效果 | 位置 |
|---|---|---|
| 固定乘区 | `dmg × 1.3` | `bkq` 步骤 8，常量 `1.3` @ `0x18362A288` |
| 条件加算 | 攻击方 `VulnerableDamage(40)` 计入 `bko` 池 | `bko` |

> 两者**同时生效**：挂上易伤 → 全伤害 ×1.3；若攻击方有"对易伤敌人伤害 480%"，则条件池再 `×(1+4.801+…)`。

### 6.3 装备/宝石/符文数值

```
# 宝石（GemData : ItemData）
GemData 继承 StatModifier 语义：Stat + Modifier + Value（固定值，不随等级）

# 符文（RuneData : ItemData）
RuneData 的 Value 是 LeveledFloat → 随符文等级成长
  value(runeLevel) = Base + max(0, runeLevel − 1) × PerLevel

# 符文套装（RuneSetData）
达到 RequiredCount 后：
  · 注入 Modifiers : StatModifier[]
  · 注入 Effects : EquipmentEffectBehavior[]
  · 授予 AbilityLevels : AbilityLevelGrant[]

# 装备固定属性（ItemData.FixedStats : StatModifier[]）
# 装备特效：EquipmentEffectBehavior 子类在运行时产出 IEnumerable<StatModifier>
#   - EquipmentEffect_AllStats：对 Core = {Str, Dex, Int} 三项各 +Bonus
#   - EquipmentEffect_StatConversion：TargetStat += SourceStat × Fraction
#   - EquipmentEffect_StatPerStatusStack：Stat += ValuePerStack × 状态层数
```

**词条生成规则**（`ItemizationConfig`）：

```
SlotPools[slot] → { Primary: List<StatType>, Secondary: List<StatType> }
GemSocketsBySlot[slot] → MaxSockets
MinLevelForSockets → 解锁孔位的最低物品等级
```

> 🔶 `Primary`/`Secondary` 对应 `AttributeCategory.Primary/Secondary`；方法 `cei(SlotAffixPool, List<StatType>, AttributeCategory)` 负责按类别归集。

**词条数值 Roll 公式** ✅（`gg.dna` RVA `0x76F5F0` / `gg.dnt` RVA `0x771590` / `gg..cctor` RVA `0x771DC0`）

```
perLevel[stat] = 系数表（55 项）                  ← Dictionary<StatType,float>
base           = itemLevel × perLevel[stat]      (+5 当 stat == WeaponDamage(20))
rollFactor     = 1.15（取最大） 或 Random(0.85, 1.15)（正常掉落）
rarityMul      = { Common:+0.2, Uncommon:+0.4, Rare:+0.5, Legendary:+0.6, 其他:+0 }
value          = (1 + rarityMul) × base × rollFactor     → 保留 3 位小数；下限 0.001
```

**技能伤害倍率** ✅（`DamageEffect`，取自 `[SerializeReference]` 载荷）

```
倍率(level)   = AttackScaling.Base + max(0, level − 1) × AttackScaling.PerLevel
attackDamage  = f(BaseDamage, 倍率, 攻强)          # te() 内合成，顺序待复核 🔶
```

> 技能的 `Effects` 为链式 SR 结构，例：`SpawnParticleAoEEffect`（Lifetime/RehitInterval）→ 内嵌 `DamageEffect` + `ApplyStatusEffectEffect`。
> 「技能倍率 = 攻击强度 × 倍率」意味着技能伤害同样吃**乘区 A/B/C**。

### 6.4 等级与经验

```
# 击杀升级所需怪物数（分段插值，GameConfig）
MobsToLevelAtLevel1 / AtLevel5 / AtLevel15 / AtLevel50 / AtMaxLevel
    → 5 个锚点做插值

# 经验获取
XP = 敌人基础生命 × XpPerBaseHealth × (1 + XpPerLevelScale × ...)
     低于 XpZeroUnderLevel 时经验为 0

# 敌人成长（分段线性，按等级区间）

# 技能等级（GameConfig）

# 符文等级
MaxRuneLevel, RuneBaseXPToLevel : long, RuneXPGrowthPerLevel

# 突破（Paragon）
ParagonMobsToLevelKnots : Vector2Int[]   ← 分段锚点
ParagonMobsGrowthPastLastKnot : int
ParagonPointsPerLevel : int

```

## 7. 属性关联关系与依赖

### 7.1 伤害乘区拓扑图

```
                      ┌──────────── 独立乘区（相互相乘） ────────────┐
BaseDamage(技能) ──×── 攻强/等级成长 ──×── 【乘区A】元素+全伤害 ──×── 【乘区B】暴击 ──×── 命中浮动 ──×── 【乘区C】条件伤害池 ──×── 【乘区D】易伤 1.3
                                                                                                                    ↓
                                                         ┌──────────── 减伤层（乘法） ────────────┐
                                            (1 − 护甲曲线) × (1 − 元素减伤) × (1 − 全局减伤)
```
其中：
- **乘区A（同池加算）** = `1 + Damage<type> + DamagePercent`
- **乘区B** = `1 + CritDamage + 装备/天赋暴伤`（仅暴击时）
- **乘区C（同池加算）** = `1 + Σ 10 项 ConditionalDamage`
- **乘区D** = 固定 `1.3`

### 7.2 属性 → 数值系统依赖表

| 属性/配置 | 影响的系统 | 依赖来源 |
|---|---|---|
| `Strength`/`Dexterity`/`Intelligence` | 通过 `EquipmentEffect_StatConversion` / `TalentEffect_StatConversion` 转化为其他属性 | `PrimaryStat`, `ItemizationConfig.Core` |
| `Damage<type>` + `DamagePercent` | 乘区 A | `ItemData.FixedStats`、`StatModifierBehavior`、宝石、符文 |
| `CritChance` / `CritDamage` | 乘区 B | 装备、`SourceCritChanceBonusBehavior`、`TalentEffect_ConditionalCrit*` |
| `ConditionalDamage` × 10 | 乘区 C | 天赋/装备条件词条 |
| `VulnerableDamage` | 乘区 C + 需 `VulnerableBehavior` 挂标 | `StatusEffectData` + `VulnerableBehavior` |
| `Armor` / `MagicResist` | 减伤层第 1 段 | 装备、`ArmorPercent`/`MagicResistPercent` |
| `Damage<type>Reduction` / `DamageReduction` | 减伤层第 2、3 段 | `DamageReductionBehavior`、装备 |
| `AttackSpeed` | 单位时间输出 | 装备、`EquipmentEffect_AbilityChannelModifier` |
| `CooldownReduction` / `ManaCostReduction` | 技能循环 | 上限 0.85 |
| `Thorns` / `ThornsDamagePercent` | 反伤（可暴击：`TalentEffect_ThornsCanCrit`） | 装备、天赋 |
| `LifeOnHit` / `LifeOnKill` / `LifeRegen` | 续航 | 装备、`TalentEffect_DotTickLifeOnHit` |
| `XPGain` / `GoldFind` / `MagicFind` / `MaterialFind` | 收益 | `LootConfig` 提供基础概率 |
| `GemSlots` | 孔位数量 | `ItemizationConfig.GemSocketsBySlot` 提供基础值 |

### 7.3 状态（StatusEffect）→ 属性 的注入路径

```
StatusEffectData.Behaviors[] (SerializeReference 多态；载荷已解码 ✅，见 08 篇 §11.1)
        │
        ├─ StatModifierBehavior.Modifiers[] (LeveledStatModifier)
        │        └─→ 产出 StatModifier → StatusEffectController.bgg()
        │                 ├─ Flat        → dict[+0x38]
        │                 ├─ PercentAdd  → dict[+0x40]
        │                 └─ PercentMult → dict[+0x48]
        │
        ├─ DamageReductionBehavior  → 由 bkq 步骤 9/11 直接读取
        ├─ DamageDealtReductionBehavior → 由 bkq 步骤 7（攻击方）读取
        ├─ DamageAmplificationBehavior  → 放大受伤
        ├─ VulnerableBehavior → 置位 SEC[+0x60]，触发 ×1.3 与 VulnerableDamage 计入池 C
        └─ ShieldBehavior → 按 MaxHPPercent 生成护盾
```
