## 1. 重导 `data/schema/`

```powershell

# 只保留三个文件，覆盖 data/schema/

```

**判据**：`dump.cs` 行数与 `// RVA:` 行数同量级（本轮 29 MB / 90,849 个方法）；`script.json` 可被
`python tools/scripts/script_index.py` 解析出约 17 万条字符串。
**常见坑**：仓库自带 `tools/thirdparty/Il2CppDumper/Il2CppDumper.exe` **不支持 v39**（报
`not a supported version[39]`）；dumper 版本与 SHA 要记进 `docs/08 §12.5`。

## 2. RVA 重算（核心一步）

```powershell
cd d:\workspace\Deskrawl-Reverse\tools\scripts
python rva_audit.py --check --falsify            # 代码侧门禁：有「已失效/无法判定」即非 0
python rva_audit.py --docs --check --falsify `
        --report ..\..\docs\reports\RVA体检报告-文档.md `
        --json   ..\..\data\schema\rva_audit_docs.json    # 文档侧门禁（同一套判据 + 分区）
```

> 文档侧已分区（`rva_audit_config.json: doc_policy`）：机器产物不扫；进度档/计划书/调研报告整篇登记为
> **历史证词**；参考文档里注明「补丁前」的证据区块用 `<!-- rva-audit:historical 理由 -->` 标记；
> 其余必须写当期地址。**分区只对「本来会判失效」的地址生效**，区块里的当期地址照常校验。
> 新增失效项、或抹掉弃用理由的文档标记，都会让 `--check` 变红。

**判据**：`--check` 退出码 0；`--falsify` 全部 PASS（故意改错一位必须判红）。
**常见坑（本轮实测）**：
1. **类名也会撞车**：混淆器重生成名字，新构建里出现同名类 `iw` 但签名交集 0/5 —— 真身是 `je`。
   脚本用「类形状自证（签名交集 ≥60%）」拦截，人工复核时**不要**因为「名字一样」就认定是同一个类。
2. **签名+Slot 也可能不唯一**（同类内多个同签名方法）：脚本退到「同签名组按序 → 类内区间 → 整类位移」三级消歧，
   证据列会写明用了哪一级；弱依据条目要人看一眼。
3. **地址宽度决定形式**：注释里 6 位是 RVA、9 位是 VA（含 `0x180000000`）。写回时保持原形式。
4. **`旧 xxx` 标记是故意保留的对照**，不要「修正」它。
5. **同名类/多类共享 RVA**：同一 RVA 可能挂在两个类名下（如 `ObscuredLong.kas` 与 `ObscuredDateTime.jtj`），
   脚本优先取与注释名同名者作证据。
6. **`.data` 元数据槽必须在 `data_refs` 登记 `expect`（条目名/字面量）**：命中当期 `script.json` 只说明
   「这个 RVA 现在是某个槽」——槽表很密，补丁后旧 RVA 几乎总会落到**别的**条目上。故判定链 ⑥ 会拿
   当期名字与登记名核对：**未登记 → 人工确认；名字不符 → 判「已失效」**（报出当期真实名字与登记名）。
   补丁后遇到这两类，按当期 `script.json` 的真实名字更新 `expect` 与源码注释即可。
7. **补丁后先看报告第 8 段（配置与文档锚点自校验）**：`docs/08 §12` 记录的构建 SHA 必须等于磁盘实测
   （`rva_audit_config.json: doc_fingerprints`），`data_refs` 每条必须带锚点。这两条是「补丁后的第一声
   警铃」——它们红了说明文档/登记仍描述上一版构建，先更新 §12 的重锚定结论再往下走。

## 弃用探针（一次性脚本，已按本文注明理由，不再重锚定）

以下文件里的地址是**已完成实验的取证痕迹**，其原始输入（补丁前 DLL / metadata）已被游戏更新覆盖，
不可复原；它们的职能已由新工具链承接。点名如下（`rva_audit.py` 会校验本文确实列了它们）：

| `tools/scripts/read_const.py` | 常量探针，标签本身带问号，目标常量不可唯一确定 | `docs/08 §11.3` 55 项系数表 + §12.2 新址表 + `pe_file.py` |
