## 8. 关键数值配置（GameConfig）

`GameConfig` 是全游戏数值中枢，字段按功能分组：

### 8.1 全局与引用

| 字段 | 类型 | 说明 |
|---|---|---|
| `DlcSlave` | `SlaveData` | DLC 从属 |
| `DlcBackEquipment` | `ItemData` | DLC 背部装备 |
| `IsDemo` | `bool` | 试玩版标记 |
| `InteractableLayer` / `GroundLayerMask` | `LayerMask` | 交互层掩码 |
| `PotionUpgradeData` | `HealingPotionUpgradeData` | 药水升级数据 |
| `Itemization` | `ItemizationConfig` | 词条配置 |
| `Loot` | `LootConfig` | 掉落配置 |

### 8.2 强化与打孔

| 字段 | 类型 | 说明 |
|---|---|---|
| `MaxEquipmentUpgradeLevel` | `int` | 装备最高强化等级 |
| `UpgradeRecipes` | `EquipmentUpgradeRecipe[]` | 按稀有度的强化配方 |
| `ExtraUpgradeMaterials` | `EquipmenSlotUpgradeMaterial[]` | 按部位附加材料 |
| `SpecialUpgradeRecipe` | `RecipeData` | 特殊强化配方 |
| `UpgradeSuccessChances` | `float[]` `[Range(0,1)]` | 逐级成功率 |
| `SocketMaterial` / `SocketMaterialAmount` / `SocketGoldPerItemLevel` | `ItemData`/`int`/`int` | 打孔材料与金币 |
| `SalvageYields` | `SalvageYield[]` | 分解产出 |
| `TalentRefundCostPerPointSpent` | `int` | 天赋洗点单价 |
| `GatherableConfigs` | `GatherableTypeConfig[]` | 采集配置 |

### 8.3 精英与 Boss

| 字段 | 说明 |
|---|---|
| `EliteHealthMultiplier` | 精英生命倍率 |
| `EliteDamageMultiplier` | 精英伤害倍率 |
| `EliteScaleMultiplier` | 精英体型倍率 |
| `BossTenacityStatus` | Boss 韧性状态 |
| `MythicBossEnrageCountdownStatus` / `MythicBossEnragedStatus` | 神话 Boss 狂暴状态 |

### 8.4 成长曲线（数值设计核心）

| 字段 | 类型 | 说明 |
|---|---|---|
| `EnemyHealthGrowthPerLevel0To30` / `31To50` / `51To70` | `float` | 敌人生命**分段**成长系数 |
| `EnemyDamageGrowthPerLevel0To30` / `31To50` / `51To70` | `float` | 敌人伤害**分段**成长系数 |
| `MobsToLevelAtLevel1` / `AtLevel5` / `AtLevel15` / `AtLevel50` / `AtMaxLevel` | `int` | 升级所需击杀数锚点 |
| `MaxPlayerLevel` | `int` | 玩家等级上限 |
| `XpPerBaseHealth` | `float` | 经验 = 生命 × 系数 |
| `XpPerLevelScale` | `float` | 等级缩放 |
| `XpZeroUnderLevel` | `int` | 低于该等级差无经验 |
| `ParagonMobsToLevelKnots` | `Vector2Int[]` | Paragon 分段锚点 |
| `ParagonMobsGrowthPastLastKnot` | `int` | 末锚点后增长 |
| `ParagonPointsPerLevel` | `int` | 每级 Paragon 点数 |
| `ParagonStats` | `ParagonStat[]` | Paragon 属性表 |
| `OfflineMobsPerHourKnots` | `Vector2Int[]` | 挂机收益分段锚点 |
| `OfflineMobsPerGoldRoll` | `float` `[Min(0.01)]` | 挂机金币换算 |
| `OfflineTimeCapHours` | `float` | 挂机收益上限时长 |
| `MaxAbilityLevel` / `AbilityBaseXPToLevel` / `AbilityXPGrowthPerLevel` | `int`/`long`/`float` | 技能等级曲线 |
| `RuneSlotUnlockLevels` / `MaxRuneLevel` / `RuneBaseXPToLevel` / `RuneXPGrowthPerLevel` | `int[]`/`int`/`long`/`float` | 符文等级曲线 |
| `DifficultyTiers` | `DifficultyTierConfig[]` | 难度档位 |
| `MinMythicDifficulty` | `WorldDifficulty` | 神话最低难度 |
| `WorldFinalBossMap` | `MapData` | 最终 Boss 地图 |
